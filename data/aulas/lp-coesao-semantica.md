# Coesão × coerência

- **Coesão**: ligação **gramatical** entre as partes (pronomes, conectores, sinônimos)
- **Coerência**: lógica do **sentido** (não contradição, relação com o mundo)
- Pode haver texto coeso e incoerente, e coerente com pouca coesão explícita

---

# Mecanismos de coesão

- **Referencial**: **anáfora** retoma o que já foi dito ("O reitor chegou. **Ele**…"); **catáfora** antecipa ("Só quero **isto**: respeito")
- **Substituição** por sinônimo, hiperônimo ou expressão: "o Brasil… **o país**"
- **Elipse**: omissão recuperável ("Fui ao setor; [eu] não encontrei ninguém")
- **Sequencial**: conectores (portanto, entretanto, além disso)
- **Operadores argumentativos**: **até / inclusive / mesmo** (argumento mais forte), **aliás / além disso** (acréscimo), **ou seja** (reformulação), **ainda** (inclusão)

---

# Relações de sentido

- **Sinonímia** / **antonímia** · **Hiperônimo** (geral: "veículo") × **hipônimo** (específico: "ônibus")
- **Homônimos**: homógrafos (colher/colhér), homófonos (**cela/sela**, **concerto/conserto**), perfeitos (são)
- **Parônimos** (parecidos): **eminente** (ilustre) × **iminente** (prestes a ocorrer); **ratificar** (confirmar) × **retificar** (corrigir); **deferir** (atender) × **diferir** (adiar/divergir); **infringir** (violar) × **infligir** (aplicar pena); **descrição** × **discrição**
- **Denotação** (sentido literal) × **conotação** (figurado)

# Figuras de linguagem

| Figura | Exemplo |
|---|---|
| Metáfora (comparação implícita) | "Aquele servidor é uma **muralha**" |
| Comparação (com conectivo) | "Forte **como** uma muralha" |
| Metonímia (autor/obra, parte/todo, continente/conteúdo) | "Li **Machado**"; "bebeu um **copo**" |
| Catacrese (metáfora desgastada) | "**pé** da mesa", "**braço** da cadeira" |
| Hipérbole / eufemismo | "morri de rir" / "ele **partiu**" (morreu) |
| Antítese / paradoxo | "riso e choro" / "dor que desatina **sem doer**" |
| Prosopopeia | "O processo **dormia** na gaveta" |
| Ironia | dizer o contrário do que se pensa |

::: cartoes
Anáfora :: Retoma termo já mencionado.
Catáfora :: Antecipa termo que vem depois.
Iminente × eminente :: Iminente = prestes a acontecer; eminente = ilustre.
Ratificar × retificar :: Ratificar = confirmar; retificar = corrigir.
Infligir × infringir :: Infligir = aplicar (pena); infringir = violar (norma).
Metonímia :: Troca por relação de proximidade (autor pela obra, parte pelo todo).
Hiperônimo :: Termo de sentido geral que abrange outros ("veículo" para "carro").
:::
