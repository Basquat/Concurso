# Componentes principais

- **CPU (processador)**: executa instruções — **UC** (unidade de controle), **ULA** (unidade lógica e aritmética) e **registradores**
- **Memória RAM**: principal, de trabalho, **volátil** (apaga ao desligar)
- **ROM / firmware (BIOS/UEFI)**: não volátil, inicializa o computador
- **Cache**: memória pequena e muito rápida entre CPU e RAM
- **Armazenamento** (memória secundária, não volátil): HD (disco magnético), **SSD** (memória flash, sem partes móveis, mais rápido), pendrive, cartão

# Periféricos

| Tipo | Exemplos |
|---|---|
| Entrada | teclado, mouse, scanner, microfone, webcam, leitor biométrico |
| Saída | monitor, impressora, caixa de som, projetor |
| Entrada e saída (mistos) | tela touchscreen, multifuncional, headset |
| Armazenamento | HD externo, pendrive, cartão SD |

- Conexões comuns: **USB** (inclusive USB-C), **HDMI** (vídeo e áudio), Bluetooth, Wi-Fi

# Unidades de medida

- **bit** (0 ou 1) · **byte** = 8 bits
- KB → MB → GB → TB: cada passo ≈ **1.024** vezes (base 2) — fabricantes de disco costumam usar 1.000
- Velocidade de rede é medida em **bits por segundo** (Mbps); tamanho de arquivo, em **bytes** (MB): 100 Mbps ≈ 12,5 MB/s

---

# Software e licenças

- **Básico** (sistema operacional: Windows, Linux, Android) · **aplicativo** (Word, navegador) · **utilitário** (antivírus, compactador) · **driver** (faz o SO conversar com o hardware)
- **Software livre**: 4 liberdades — executar, estudar (código aberto), redistribuir e modificar (ex.: Linux, LibreOffice)
- **Freeware**: gratuito, mas não necessariamente livre · **Shareware**: teste por tempo/limitado · **Proprietário**: licença restrita
