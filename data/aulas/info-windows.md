# Interface

- **Menu Iniciar** centralizado, **barra de tarefas**, área de notificação (relógio, rede, som), **Widgets**
- **Snap Layouts**: organizar janelas lado a lado (Win + setas ou passando o mouse no botão maximizar)
- **Áreas de trabalho virtuais** (Win+Tab) · **Configurações** (Win+I) substitui a maior parte do Painel de Controle
- Requisitos que marcaram o Windows 11: **TPM 2.0** e **Inicialização Segura (Secure Boot)**

---

# Atalhos com a tecla Windows

| Atalho | Ação |
|---|---|
| Win+E | Explorador de Arquivos |
| Win+D | mostrar a área de trabalho |
| Win+L | **bloquear** a sessão |
| Win+I | Configurações |
| Win+V | **histórico** da área de transferência |
| Win+Shift+S | captura de tela (Ferramenta de Captura) |
| Win+Tab | Visão de Tarefas |
| Win+. | painel de emojis |
| Win+R | Executar |

---

# Outros atalhos clássicos

| Atalho | Ação |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | copiar / recortar / colar |
| Ctrl+Z / Ctrl+Y | desfazer / refazer |
| Alt+Tab | alternar janelas |
| Alt+F4 | fechar a janela ativa |
| Ctrl+Shift+Esc | **Gerenciador de Tarefas** |
| Ctrl+Alt+Del | tela de segurança (bloquear, trocar usuário, gerenciador) |
| Print Screen | captura a tela inteira |

# Segurança e manutenção

- **Segurança do Windows** (Microsoft Defender): antivírus, **firewall**, proteção contra ransomware (acesso controlado a pastas)
- **Windows Update**: correções de segurança — mantenha ativo
- **BitLocker**: criptografia do disco · **Histórico de Arquivos** e pontos de restauração para recuperação
- Contas: **administrador** (instala e altera o sistema) × **padrão** (uso diário, mais seguro)
