# Computação em nuvem

- Recursos (armazenamento, processamento, programas) acessados **pela internet**, sob demanda
- **SaaS** (software como serviço): uso o programa pronto — Microsoft 365, Gmail
- **PaaS** (plataforma): ambiente para desenvolver/publicar aplicações
- **IaaS** (infraestrutura): máquinas virtuais, redes e discos alugados
- Modelos: **pública**, **privada**, **híbrida**

---

# Microsoft 365 na prática

- **OneDrive**: arquivos pessoais na nuvem, sincronizados com o computador (Arquivos Sob Demanda)
- **SharePoint**: sites e bibliotecas de documentos de equipes
- **Teams**: chat, reuniões, canais e arquivos da equipe (os arquivos dos canais ficam no SharePoint)
- **Coautoria**: várias pessoas editam o mesmo documento **ao mesmo tempo**
- **Histórico de versões**: restaurar uma versão anterior · **Salvamento automático** em arquivos na nuvem

---

# Compartilhar com segurança

- Links com permissão: **pode exibir** × **pode editar**; para **pessoas específicas** × qualquer pessoa com o link
- Defina **data de expiração** e senha quando disponível
- Não compartilhe dados pessoais além do necessário (**LGPD**)

---

# Noções de redes e backup

- **LAN** (rede local), **WAN** (longa distância), **Wi-Fi** (sem fio), **roteador** (liga redes / à internet), **switch** (liga dispositivos da rede local)
- Compartilhamento de recursos: impressoras e pastas de rede (`\\servidor\pasta`)
- **Backup 3-2-1**: **3** cópias, em **2** mídias diferentes, **1** fora do local (nuvem)
- Tipos: **completo**, **incremental** (só o que mudou desde o último backup), **diferencial** (o que mudou desde o último completo)

::: cartoes
SaaS :: Software pronto acessado pela nuvem (Microsoft 365, Gmail).
IaaS :: Infraestrutura (máquinas virtuais, discos) sob demanda.
Coautoria :: Edição simultânea do mesmo arquivo por várias pessoas.
Backup incremental :: Copia o que mudou desde o último backup de qualquer tipo.
Backup diferencial :: Copia o que mudou desde o último backup completo.
Regra 3-2-1 :: 3 cópias, 2 mídias, 1 fora do local.
:::
