# As dez classes

- **Variáveis**: substantivo, artigo, adjetivo, numeral, pronome, verbo
- **Invariáveis**: advérbio, preposição, conjunção, interjeição
- A classe depende do **uso**: "o **jantar** está pronto" (substantivo) × "vamos **jantar**" (verbo) — é a **derivação imprópria**

---

# Pronomes que mais caem

- **Pessoais retos** (eu, tu, ele…) = sujeito; **oblíquos** (me, te, o, a, lhe…) = complemento
- **o/a** → objeto direto; **lhe** → objeto indireto: "Entreguei-**lhe** o processo"
- **Demonstrativos**: **este** (perto de quem fala / o que vem), **esse** (perto do ouvinte / o que já foi dito), **aquele** (distante)
- **Relativos**: que, quem, o qual, cujo (posse, sem artigo depois: "o autor **cujo** livro li"), onde (lugar físico)

---

# Formação de palavras

| Processo | Exemplo |
|---|---|
| Derivação prefixal / sufixal | infeliz / felizmente |
| Parassintética (prefixo e sufixo **ao mesmo tempo**) | entardecer, emudecer, avermelhar |
| Regressiva (encurta; verbo → substantivo) | combate (de combater), ajuda |
| Imprópria (muda a classe) | o sim, o jantar |
| Composição por **justaposição** (sem perda) | girassol, passatempo, guarda-chuva |
| Composição por **aglutinação** (com perda) | planalto, aguardente, embora |
| Hibridismo (línguas diferentes) | automóvel, sociologia, televisão |

# Colocação pronominal

- **Próclise** (antes do verbo) — obrigatória com palavras atrativas: negação (**não, nunca**), advérbios sem vírgula, pronomes relativos e indefinidos, conjunções subordinativas: "Não **me** disseram", "Espero que **se** resolva"
- **Mesóclise** — futuro do presente/pretérito sem atrativo: "Far-**se**-á a análise", "Dir-**lhe**-ia"
- **Ênclise** — início de frase, imperativo afirmativo, gerúndio, infinitivo impessoal: "Informo-**lhe** que…"
- Norma-padrão: não se inicia frase com pronome oblíquo átono

::: quiz
? Assinale a colocação conforme a norma-padrão:
- [ ] Me informaram que o prazo acabou.

- [x] Informar-se-á o resultado amanhã.

::: cartoes
Parassíntese :: Prefixo e sufixo acrescentados ao mesmo tempo (entardecer, emudecer).
Aglutinação × justaposição :: Aglutinação perde fonema (planalto); justaposição não (girassol).
Cujo :: Pronome relativo de posse; não admite artigo depois ("cujo o" é erro).
Lhe :: Objeto indireto (a ele/a ela).
Mesóclise :: Com futuro do presente ou do pretérito, sem palavra atrativa (far-se-á).
Próclise obrigatória :: Com negação, advérbio sem vírgula, pronome relativo/indefinido e conjunção subordinativa.
:::
