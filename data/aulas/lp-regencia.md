# Verbos que mudam de sentido

| Verbo | Sentido | Regência |
|---|---|---|
| **Assistir** | ver, presenciar | VTI (a): "assisti **ao** filme" |
| | ajudar, dar assistência | VTD: "o médico assistiu **o** paciente" |
| | caber (direito) | VTI (a): "esse direito assiste **ao** servidor" |
| **Aspirar** | desejar | VTI (a): "aspira **ao** cargo" |
| | inalar | VTD: "aspirou **o** ar" |
| **Visar** | pretender | VTI (a): "visa **ao** bem comum" (a VTD também é aceita) |
| | mirar / pôr visto | VTD: "visou **o** alvo", "visou **o** cheque" |

# Os mais cobrados

- **Preferir** algo **a** outra coisa — nunca "mais", "do que": "Prefiro estudar **a** sair"
- **Implicar** (acarretar) → VTD: "A falta **implica** advertência" (sem "em", na norma-padrão)
- **Chegar / ir** → preposição **a**: "Chegou **ao** setor" (não "chegou no setor")
- **Obedecer / desobedecer** → VTI: "obedecer **ao** regulamento"
- **Pagar / perdoar**: coisa = OD, pessoa = OI: "paguei **a** conta **ao** fornecedor"
- **Lembrar / esquecer**: sem pronome → VTD ("esqueci **o** prazo"); com pronome → VTI ("esqueci-**me do** prazo")
- **Namorar** → VTD: "namora **a** colega" · **simpatizar** → com, sem pronome

# Regência nominal

- **apto a/para**, **ansioso por/para**, **acessível a**, **compatível com**, **contrário a**, **residente/situado em**, **favorável a**, **imune a/de**, **preferível a**
- Regência e crase andam juntas: "Ele é favorável **à** proposta" (favorável a + a proposta)

::: quiz

- [ ] Prefiro mais trabalhar do que ficar parado.
- [x] O candidato aspira ao cargo de analista.

= Aspirar (desejar) pede "a"; preferir dispensa "mais" e usa "a"; implicar (acarretar) é transitivo direto.

::: cartoes
Assistir (ver) :: VTI, preposição a: "assistir ao jogo".
Aspirar (desejar) :: VTI: "aspirar ao cargo".
Preferir :: Preferir algo a algo (sem "mais" e sem "do que").
Implicar (acarretar) :: VTD: "implica advertência".
Esquecer-se :: Com pronome pede "de": "esqueci-me do prazo".
Chegar :: Preposição a: "chegar ao trabalho".
:::
