# Faixa de opções (guias)

- **Página Inicial**: fonte, parágrafo, estilos, localizar/substituir
- **Inserir**: tabelas, imagens, formas, cabeçalho/rodapé, número de página, quebra de página
- **Layout**: margens, orientação, tamanho, colunas, **quebras** (página e seção)
- **Referências**: **sumário**, notas de rodapé, citações · **Revisão**: ortografia, comentários, **Controlar Alterações**
- **Exibir**: modos (Layout de Impressão, Leitura, Web, Estrutura de Tópicos), régua, zoom

---

# Formatação

- **Fonte**: tipo, tamanho, negrito, itálico, sublinhado, cor, realce
- **Parágrafo**: alinhamento (esquerda, centralizado, direita, **justificado**), recuo, **espaçamento entre linhas**, marcadores e numeração
- **Estilos** (Título 1, Título 2…): padronizam o documento e geram o **sumário automático**
- **Pincel de formatação**: copia a formatação de um trecho para outro

# Atalhos (Word em português)

| Atalho | Ação |
|---|---|
| Ctrl+N / Ctrl+I / Ctrl+S | negrito / itálico / sublinhado |
| Ctrl+B | salvar |
| Ctrl+O / Ctrl+A | novo documento / abrir |
| Ctrl+T | selecionar tudo |
| Ctrl+E / Ctrl+J | centralizar / justificar |
| Ctrl+L / Ctrl+U | localizar / substituir |
| Ctrl+Enter | quebra de página |
| F7 | ortografia e gramática |
| F12 | salvar como |
| Shift+F3 | alternar maiúsculas/minúsculas |

---

# Recursos que caem

- **Quebra de seção**: permite orientação, margens ou cabeçalhos **diferentes** em partes do documento
- **Controlar Alterações**: registra inserções e exclusões para aceitar/rejeitar
- **Mala direta**: gera várias cartas a partir de uma lista (Excel)
- Salvar como **PDF** e formatos: .docx (padrão), .doc (antigo), .dotx (modelo), .odt (ODF)
