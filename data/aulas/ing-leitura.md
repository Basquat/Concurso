# Antes de ler

- Leia o **título**, subtítulos, imagens e a **fonte**: o tema já orienta o vocabulário
- Leia as **perguntas primeiro**: você sabe o que procurar
- Não traduza palavra por palavra — busque o **sentido geral**

---

# Skimming e scanning

- **Skimming**: leitura rápida para captar a **ideia principal** (primeiro e último parágrafos, primeira frase de cada parágrafo)
- **Scanning**: varredura para achar uma **informação específica** (datas, números, nomes, siglas)
- **Palavras-chave** e **cognatos** (*technology, important, system*) sustentam a compreensão

---

# Inferência e referência

- **Inferência pelo contexto**: a palavra desconhecida costuma ser explicada por exemplo, contraste ou sinônimo próximo
- **Referência pronominal**: identifique a que se referem *it, they, this, which, whose*
- **Afixos** ajudam: *un-* / *dis-* (negação), *-less* (sem), *-ful* (cheio de), *-ly* (advérbio), *re-* (de novo)

---

# Em questões de prova

- "According to the text…" → a resposta está **escrita** no texto
- "It can be inferred…" → conclusão **lógica** a partir do texto, sem extrapolar
- Desconfie de alternativas com **always, never, all, only** quando o texto é moderado
- Os distratores costumam usar palavras do texto com sentido trocado
