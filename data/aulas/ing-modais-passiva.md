# Modais

| Modal | Ideia |
|---|---|
| **can / could** | habilidade, permissão (could: passado ou pedido educado) |
| **may / might** | possibilidade (might: mais remota); permissão formal |
| **must** | obrigação forte ou dedução lógica |
| **have to** | obrigação externa (regra) |
| **should / ought to** | conselho, recomendação |

- *Mustn't* = proibição; *don't have to* = **não é necessário**
- Modais não recebem *-s* nem *to*: *He **can** speak*, não *He cans / He can to*

---

# Voz passiva

- Estrutura: **be** (no tempo do verbo) + **particípio** — *The data **is stored** in the cloud.*
- Agente com **by**: *The report **was written by** the auditors.*
- Muito comum em textos técnicos, quando o agente não importa

---

# Condicionais (if clauses)

| Tipo | Estrutura | Uso |
|---|---|---|
| Zero | if + present, present | verdade geral |
| **First** | if + present, **will** + verbo | possibilidade real no futuro |
| **Second** | if + **past**, **would** + verbo | hipótese irreal no presente |
| **Third** | if + **had** + particípio, **would have** + particípio | hipótese sobre o passado |

---

# Pronomes relativos

- **who** (pessoas) · **which** (coisas) · **that** (pessoas ou coisas, em orações restritivas)
- **whose** (posse: *cujo*) · **where** (lugar) · **when** (tempo)

::: cartoes
mustn't x don't have to :: Proibição x não necessidade.
Voz passiva :: be + particípio (o agente vem com by).

whose :: Pronome relativo de posse (cujo).
should :: Conselho ou recomendação.
:::
