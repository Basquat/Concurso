# Conceitos

- **População**: todos os elementos de interesse; **amostra**: subconjunto observado
- **Parâmetro** (da população) x **estatística** (da amostra)
- Variáveis: **qualitativas** (nominal, ordinal) e **quantitativas** (discreta — contagem; contínua — medida)

---

# Frequências e gráficos

- Frequência **absoluta** (contagem), **relativa** (proporção) e **acumulada**
- **Histograma**: variáveis contínuas em classes; **barras/colunas**: categorias; **setores (pizza)**: partes de um todo; **linhas**: evolução no tempo; **box plot**: quartis e valores atípicos

---

# Medidas de posição

- **Média**: Σx/n — sensível a valores extremos
- **Mediana**: valor central do rol (n par: média dos dois centrais) — **robusta** a extremos
- **Moda**: valor mais frequente (pode não existir ou haver várias)
- Quartis: Q1 (25%), Q2 = mediana (50%), Q3 (75%); amplitude interquartil = Q3 − Q1
- Distribuição **assimétrica à direita**: moda < mediana < média

---

# Medidas de dispersão

- **Amplitude** = máximo − mínimo
- **Variância** σ² = Σ(x − x̄)²/n (populacional) ou /(n − 1) (amostral)
- **Desvio padrão** = √variância (mesma unidade dos dados)
- **Coeficiente de variação** CV = σ/x̄ — compara dispersões em escalas diferentes
- Somar uma constante a todos os dados **não altera** a variância; multiplicar por k multiplica o desvio por |k| e a variância por k²

::: quiz
? Todos os salários de uma equipe recebem aumento fixo de R$ 300. O desvio padrão dos salários:
- [ ] aumenta R$ 300
- [x] não se altera
- [ ] dobra
- [ ] diminui
= Somar uma constante desloca os dados sem mudar a dispersão.
:::

::: cartoes
Mediana :: Valor central do rol; não é afetada por valores extremos.
Variância amostral :: Divide por n − 1.
Coeficiente de variação :: Desvio padrão ÷ média.
Assimetria à direita :: Moda < mediana < média.
Somar constante aos dados :: A média muda; a variância e o desvio padrão não.
:::
