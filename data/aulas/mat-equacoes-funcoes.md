# Equações

- **1º grau**: isolar x → 3x + 5 = 20 → x = 5
- **2º grau**: ax² + bx + c = 0 → **Δ = b² − 4ac**; x = (−b ± √Δ) / 2a
  - Δ > 0: duas raízes reais distintas · Δ = 0: uma raiz (dupla) · Δ < 0: sem raízes reais
- **Soma** das raízes = −b/a · **Produto** = c/a

---

# Sistemas lineares

- **Substituição**: isole uma variável e substitua na outra equação
- **Adição**: multiplique as equações para cancelar uma variável e some
- Exemplo: x + y = 10 e x − y = 4 → somando: 2x = 14 → **x = 7, y = 3**

---

# Função afim e quadrática

- **Afim** f(x) = ax + b: gráfico é **reta**; a = coeficiente angular (a > 0 cresce); b = onde corta o eixo y; raiz x = −b/a
- **Quadrática** f(x) = ax² + bx + c: gráfico é **parábola**; a > 0 concavidade para cima (tem **mínimo**)
- **Vértice**: xᵥ = −b/2a; yᵥ = −Δ/4a — usado em problemas de **máximo lucro / mínima área**

---

# Exponencial e logaritmo

- Exponencial f(x) = aˣ (a > 0, a ≠ 1): crescimento de juros compostos, populações
- **logₐ b = x ⇔ aˣ = b**
- Propriedades: log(a·b) = log a + log b · log(a/b) = log a − log b · log aⁿ = n·log a
- log 1 = 0 em qualquer base; logₐ a = 1
