# Recursos comuns

- **Abas**, **favoritos** (marcadores), **histórico**, **downloads**, **extensões**, sincronização com conta
- **Cookies**: pequenos arquivos que sites gravam para lembrar sessão e preferências (também usados para rastreamento)
- **Cache**: cópia local de páginas/imagens para carregar mais rápido
- **Pop-up**: janela aberta automaticamente — pode ser bloqueada

---

# Navegação anônima / privada

- Chrome: **janela anônima** (Ctrl+Shift+N) · Firefox: **janela privativa** (Ctrl+Shift+P) · Edge: **InPrivate** (Ctrl+Shift+N)
- **Não guarda** histórico, cookies e dados de formulário **após fechar** a janela
- **Não esconde** a navegação do provedor, da rede do trabalho ou dos sites visitados; **downloads e favoritos** criados permanecem

> [!prova] Pegadinha
> Navegação anônima **não** é sinônimo de proteção contra vírus nem de anonimato na rede.

# Atalhos que caem

| Atalho | Ação |
|---|---|
| Ctrl+T | nova aba |
| Ctrl+W | fechar aba |
| Ctrl+Shift+T | reabrir aba fechada |
| Ctrl+Tab | próxima aba |
| Ctrl+H | histórico |
| Ctrl+J | downloads |
| Ctrl+D | adicionar aos favoritos |
| Ctrl+F | localizar na página |
| F5 / Ctrl+F5 | recarregar / recarregar ignorando o cache |
| Ctrl + / Ctrl − / Ctrl 0 | zoom |

# Segurança ao navegar

- Confira o **cadeado** e o domínio exato (golpes trocam letras: ufba**.com**.br, uf**b**a-gov…)
- Mantenha navegador e extensões **atualizados**; instale extensões só de lojas oficiais
- Não salve senhas em computadores compartilhados
