# Estrutura

- Arquivo **.pptx** (modelo: .potx; apresentação que abre direto no modo apresentação: **.ppsx**)
- **Layouts** (Título, Título e Conteúdo, Comparação…) e **temas** (cores, fontes, efeitos)
- **Slide Mestre**: define a formatação padrão de **todos** os slides (logotipo, fonte, rodapé) — guia Exibir

---

# Transição × animação

- **Transição**: efeito na **passagem de um slide para outro** (guia Transições)
- **Animação**: efeito em **objetos dentro** do slide — entrada, ênfase, saída e trajetória (guia Animações)
- Ambas podem ser **ao clicar** ou **automáticas** (com tempo)

---

# Modos de exibição

- **Normal** (edição) · **Classificação de Slides** (reordenar) · **Anotações** · **Modo de Leitura**
- **Modo do Apresentador**: o público vê o slide; quem apresenta vê anotações, próximo slide e cronômetro

---

# Apresentando

| Atalho | Ação |
|---|---|
| F5 | apresentar **do início** |
| Shift+F5 | apresentar **do slide atual** |
| Esc | encerrar |
| B / W | tela preta / branca |
| número + Enter | ir para o slide |

- Exportar: **PDF**, vídeo (.mp4), folhetos com anotações

::: quiz
? O efeito aplicado a um gráfico que surge dentro do slide ao clicar é:
- [ ] transição
- [x] animação
- [ ] slide mestre
= Efeitos em objetos dentro do slide são animações; transição é entre slides.
:::

::: cartoes
F5 :: Apresenta desde o primeiro slide.
Shift+F5 :: Apresenta a partir do slide atual.
Slide Mestre :: Padroniza a formatação de todos os slides.
Transição :: Efeito na passagem entre slides.
Animação :: Efeito em objetos dentro do slide.
.ppsx :: Abre direto no modo de apresentação.
:::
