# Cognatos verdadeiros

- Palavras parecidas **com o mesmo sentido**: *information, important, government, public, system, economy, digital*
- Terminações: *-tion* → -ção (*administration*); *-ty* → -dade (*security*); *-ous* → -oso (*famous*); *-ly* → -mente (*rapidly*)

---

# Falsos cognatos (1)

| Inglês | Significa | Não é |
|---|---|---|
| **actually** | na verdade | atualmente (*currently*) |
| **eventually** | finalmente, com o tempo | eventualmente (*occasionally*) |
| **pretend** | fingir | pretender (*intend*) |
| **push** | empurrar | puxar (*pull*) |
| **library** | biblioteca | livraria (*bookstore*) |
| **college** | faculdade | colégio (*high school*) |

---

# Falsos cognatos (2)

| Inglês | Significa | Não é |
|---|---|---|
| **parents** | pais | parentes (*relatives*) |
| **realize** | perceber | realizar (*accomplish*) |
| **sensible** | sensato | sensível (*sensitive*) |
| **support** | apoiar | suportar, tolerar (*stand*) |
| **lunch** | almoço | lanche (*snack*) |
| **exquisite** | requintado | esquisito (*weird*) |
| **appoint** | nomear | apontar (*point*) |
| **resume** | retomar | resumir (*summarize*) |

---

# Mais armadilhas de prova

- **assume** = supor (não "assumir" um cargo, que é *take on*)
- **attend** = comparecer (não "atender", que é *answer/serve*)
- **data** = dados; **fabric** = tecido; **novel** = romance; **costume** = fantasia; **legend** = legenda de mapa/lenda
- **policy** = política (diretriz); **politics** = política partidária
